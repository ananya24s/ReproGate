# Decision 002

## ReproGate Visual Identity

Status: Accepted

ReproGate's signature visual will be a "Living Code Constellation."

Repository files are represented as particles/nodes. Relationships between files form connections. As verification progresses, irrelevant nodes fade while relevant files remain highlighted, visually representing repository narrowing and evidence discovery.

The visualization must reflect real ReproGate state rather than serve as decorative animation.

Implementation is deferred until the core v1 verification pipeline is functional.

Design principles:
- dark, restrained developer-tool aesthetic
- large typography and negative space
- subtle particle motion
- no generic space/rocket imagery
- no cyberpunk or hacker aesthetic
- visualization should explain the verification process
